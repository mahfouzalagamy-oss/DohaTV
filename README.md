# DohaTV | دوحة TV - الشاشة الذكية

**لوحة تلفزيون عربية ذكية مفتوحة المصدر** تعرض الوقت، التاريخ الهجري والميلادي، مواقيت الصلاة، الطقس، مباريات اليوم، الأذكار المتغيرة، والأخبار العاجلة في شاشة واحدة مناسبة للتلفزيون والريموت كنترول.

## المزايا الجديدة والتحسينات

- **لوحة تحكم شاشة واحدة شاشات موحدة:** تصميم عصري وأنيق يتكيف تلقائيًا مع شاشات التلفزيون وشاشات 16:9.
- **ساعة رقمية بارزة وتاريخ هجري وميلادي:** عرض مباشر ومحدث بالثواني.
- **مواقيت الصلاة والتنبيه بالأذان:** مع إمكانية اختيار المؤذن (أذان مكة المكرمة، أذان المسجد الحرام، أذان المسجد النبوي، الأذان المصري، وأذان الشيخ مشاري العفاسي) والتحكم بالريموت.
- **أخبار عاجلة من مصادر متعددة:** جلب تلقائي لأهم الأخبار العربية والعالمية المباشرة في شريط متحرك أسفل الشاشة.
- **ذكر دائم متغير كل دقيقة:** عرض أذكار وأدعية صحيحة تتغير تلقائياً كل 60 ثانية مع عداد تنازلي.
- **مباريات اليوم المهمة:** جدول لأهم المباريات القارية والعالمية (دوري أبطال أوروبا، الدوري الإنجليزي، الإسباني، المصري، دوري أبطال إفريقيا).
- **عداد رمضان:** عرض الأيام المتبقية لرمضان المبارك بشكل مصغر وأنيق.
- **دعم كامل لريموت التلفزيون (D-Pad Navigation):** إمكانية التنقل بالأسهم (يمين، يسار، أعلى، أسفل) واختيار العناصر بزر Enter.
- **وضع شاشة التوقف عند الخمول (15 دقيقة):** تفعيل تلقائي لشاشة التوقف الأنيقة بعد 15 دقيقة من خمول التلفاز أو الضغط على زر الهوم، ويمكن الخروج منها بضغط أي زر في الريموت.
- **ثلاثة ثيمات:** (ثيم داكن حديث، ثيم إسلامي كلاسيكي، ثيم زمردي).

## استخدام التطبيق وبناؤه

- **على الويب:** افتح `index.html` في المتصفح أو عبر أي خادم ملفات ثابت.
- **على Android TV:** قم ببناء ملف APK محلياً باستخدام Gradle:
  ```bash
  ./gradlew assembleDebug
  ```
  أو نزل ملف APK المبنياً تلقائياً من تبويب Actions في المستودع وقُم بتثبيته على التلفاز.
